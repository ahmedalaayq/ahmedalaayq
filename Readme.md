# 🧠 Architecture & Engineering

```text
Flutter
   │
   ├── Presentation
   │    ├── Bloc / Cubit
   │    └── UI / Widgets
   │
   ├── Domain
   │    ├── Entities
   │    ├── Use Cases
   │    └── Repository Contracts
   │
   └── Data
        ├── Models
        ├── Data Sources
        ├── Repository Implementations
        └── API / Backend
```

### Principles I Follow

* Clean Architecture
* SOLID
* Separation of Concerns
* Repository Pattern
* Dependency Injection
* Reusable components
* Testable and maintainable code
* Performance-conscious UI
